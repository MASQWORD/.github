# MASQWORD

Independent game studio building social multiplayer games for Discord and the web.

**MASQWORD** — a party game for Discord voice chats: tell a story out loud and sneak three secret words past your friends.
Real-time multiplayer for 2–8 players, solo or teams, in English, Spanish and Russian.
